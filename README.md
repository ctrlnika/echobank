# Clarity Banking

I have already built the first HTML prototype of this application and uploaded the code.

Your job is NOT to redesign it from scratch.

Instead, analyze every screen and transform it into a polished, production-quality MVP that could realistically be presented by a fintech startup to executives at a major UK bank.

Context

This project is for a banking innovation challenge.

The goal is to redesign digital banking for customers with complete visual impairment.

The application should feel like something Barclays, Monzo, Revolut or Apple would release.

Every design decision must improve accessibility while remaining beautiful and modern.

Your Role

Act as:

 Senior Product Designer

 Accessibility Specialist (WCAG 2.2 AAA)

 UX Researcher

 Fintech Product Manager

 Frontend Engineer

 AI Product Designer

Challenge my assumptions.

If something is weak, replace it with a better solution.

Do not simply agree with my design.

Design Goals

Create an experience that is:

 effortless

 trustworthy

 calming

 voice-first

 screen-reader friendly

 gesture friendly

 cognitively simple

 premium

 futuristic

The interface should look like it belongs in 2027.

Accessibility Requirements

Every feature must work without vision.

Prioritise:

 Voice navigation

 Haptic feedback

 Large touch targets

 High contrast

 Screen reader optimisation

 Semantic HTML

 Keyboard navigation

 Minimal cognitive load

 Error prevention

 Confirmation before payments

AI Features

If appropriate, improve the prototype with intelligent features such as:

 AI banking assistant

 Conversational banking

 Smart spending summaries

 Natural language commands

 Transaction explanations

 Context-aware help

 Emergency assistance

 AI onboarding

Only include features that genuinely improve accessibility.

Treat this as if you were a founding designer at Apple and the CTO of a major UK bank reviewing the product before launch.
